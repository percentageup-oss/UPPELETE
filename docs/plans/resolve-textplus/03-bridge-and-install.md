# 03 — Bridge + plugin install + connection status

## Goal
After this brief:
- **Settings → DaVinci Resolve** installs, reinstalls or removes the `KathaCut` script in Resolve's Scripts folder.
- In Resolve, **Workspace → Scripts → KathaCut** starts the Lua bridge. It launches KathaCut if it isn't running,
  and focuses it if it is.
- KathaCut shows a status pill: *DaVinci: not connected* or *DaVinci: <project> › <timeline>*. Clicking it while
  not connected shows the hint "In Resolve: Workspace → Scripts → KathaCut" and, if the script isn't installed yet,
  an **Install plugin** button.
- Commands that work end to end: `ping`, `timelineInfo` and `disconnect`. No caption features yet.

Read `docs/plans/resolve-textplus/README.md` (architecture, mailbox protocol, rules) and
**`docs/decisions/0008-resolve-textplus.md`** (confirmed facts; it wins over this brief) first.

## Steps

### Lua side (`resources/resolve/`)
1. `json.lua`: a minimal JSON module for Lua 5.1, returning `{ encode, decode, null }`. The decoder handles
   objects, arrays, strings with escapes including `\uXXXX` and surrogate pairs (converted to UTF-8), numbers,
   booleans and null (a sentinel). Raw UTF-8 bytes pass through unchanged, which matters for Malayalam. The
   encoder escapes `"`, `\` and control characters, and tells arrays from objects (sequential 1..n keys = array;
   an empty table = `{}` unless it is marked as an array). Keep it under ~250 lines, and put a header saying it was
   written for KathaCut, GPL-3.0-or-later.
2. `bridge.lua`. It expects a global `KATHACUT = { resourcesDir, mailboxDir, launch = { kind, exe, args } }` set
   by the launcher.
   - `dofile(resourcesDir .. "/json.lua")`.
   - `writeJson(name, tbl)`: write `<name>.tmp`, then rename it over the target (per ADR: remove first if rename
     can't overwrite). `readJson(name)`: returns nil if the file is missing or can't be parsed.
   - On start: `sessionId = tostring(os.time()) .. "-" .. tostring(math.random(1e9))` (call `math.randomseed` first).
     Write `status.json`.
   - **Launch the app** if `app.json` is missing or its `heartbeatAt` is older than 5 s:
     - `kind == "windows"`: `os.execute('start "" "' .. exe .. '"' .. args)`.
     - `kind == "mac-app"`: `os.execute('open -a "' .. bundle .. '"')`.
     - `kind == "exec"` (dev): `os.execute('"' .. exe .. '"' .. args .. ' &')`, or the `start` form on Windows.
     - Every arg is wrapped in `"`. The installer guarantees there are no `"` characters.
   - Main loop: every `bmd.wait(POLL)` (the ADR interval, default 0.15 s), read `request.json`. If it exists and
     its `sessionId` matches, delete it, dispatch `handlers[command](params)` inside `pcall`, and write
     `response.json`. Refresh `status.json` about every 1 s. `projectName`/`timelineName` in it are cheap `pcall`ed
     calls that may be nil. Exit the loop on `disconnect`, when `app.json` has `quitting = true`, when
     `app.json`'s `heartbeatAt` is older than 60 s, or when no `app.json` appears within 60 s of a launch. On exit,
     write a final `status.json` with `closed = true`.
   - Handlers: `ping` returns `{ pong = true, version = BRIDGE_VERSION }`. `timelineInfo` returns `{ projectName,
     timelineName, timelineId, startFrame, endFrame, frameRate /* the raw string */, dropFrame, width, height }`,
     or an error "No timeline is open in Resolve". `disconnect` returns `{}`, then exits.
   - Unknown commands get `ok=false, error="Unknown command"`. Never `load` or `loadstring` anything from a
     request.
   - Set `BRIDGE_VERSION = 1` at the top.
3. Launcher template. It isn't a file: TS generates it (step 4). Its content:
   ```lua
   -- Generated by KathaCut. Reinstall from KathaCut → Settings → DaVinci Resolve if KathaCut moves.
   KATHACUT = { resourcesDir = [[...]], mailboxDir = [[...]], launch = { kind = "windows", exe = [[...]], args = { } } }
   dofile(KATHACUT.resourcesDir .. "/bridge.lua")
   ```

### Main process (`electron/resolve/`)
4. `install.ts`:
   - `resolveScriptsDir(platform)`:
     - win32: `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility`
     - darwin: `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility`
     - other platforms: unsupported.
   - `bridgeResourcesDir()`: `path.join(process.resourcesPath, 'resolve')` when packaged, otherwise
     `path.join(app.getAppPath(), 'resources', 'resolve')`.
   - `launchSpec()`:
     - packaged win32: `{ kind: 'windows', exe: process.execPath }`
     - packaged darwin: `{ kind: 'mac-app', exe: <the .app bundle path derived from execPath> }`
     - dev: `{ kind: 'exec', exe: process.execPath, args: [app.getAppPath()] }`
   - `pluginInfo()` returns `{ supported, installed, upToDate, scriptPath }`. `upToDate` means the file's content
     equals what would be generated now.
   - `installPlugin()` creates the directory (`mkdir -p`) and writes `KathaCut.lua` atomically. It rejects any path
     containing `"` or `]]` with a clear error.
   - `uninstallPlugin()` removes only `KathaCut.lua`.
   - It never touches other files in that folder. The mailbox dir is `<userData>/resolve-bridge`.
5. `bridge.ts`, a `ResolveBridge` class (singleton accessor like `getConfigStore` in the MCP code):
   - `start()`: create the mailbox dir. Write `app.json` `{v:1, pid, heartbeatAt}` every 2 s. Poll `status.json`
     every 1 s (read + zod parse; `fs.watch` is unreliable across platforms, so polling is fine).
   - State: `{ state: 'disconnected' } | { state: 'connected', sessionId, product, version, projectName,
     timelineName, busy }`. It is connected while `heartbeatAt` is within 5 s of now and `closed` is not set.
     Broadcast `resolve:status-changed` to all windows on every change.
   - When a **new** `sessionId` is seen, focus the main window (`show()`, `focus()`, restore if minimized).
   - `request<T>(command, params, schema, timeoutMs = 10_000)`: a serial promise queue with incrementing `seq`.
     Write `request.json`, poll `response.json` every 100 ms, and accept only a matching `sessionId` + `seq`, then
     delete it. Validate with zod. On timeout, throw "DaVinci Resolve did not answer. Is the KathaCut script
     still running in Resolve?". Fail immediately when disconnected.
   - `stop()` on app quit: write `app.json` with `quitting: true` and stop the timers.
6. `src/core/resolveIpc.ts`: zod schemas for `status.json`, the response envelope, the `timelineInfo` result,
   plugin info, and the `ResolveStatus` view type. Parse the frame rate string into rational `{num, den}` with a
   helper `parseResolveFps` (mapping table in the README). Put that helper in `src/resolve/frames.ts`, because
   brief 05 reuses it.
7. `ipc.ts`, `registerResolveIpc()`:
   - `resolve:status`
   - `resolve:plugin-info`
   - `resolve:install-plugin`
   - `resolve:uninstall-plugin`
   - `resolve:timeline-info` (calls the bridge)
   - `resolve:disconnect`
   Register it in `electron/main.ts` next to `registerMcpIpc`. Start the bridge in `whenReady` and stop it on quit.
8. Preload + `src/env.d.ts`: `resolveStatus()`, `onResolveStatus(listener)` (returns an unsubscribe),
   `resolvePluginInfo()`, `installResolvePlugin()`, `uninstallResolvePlugin()`, `resolveTimelineInfo()` and
   `resolveDisconnect()`. Validate event payloads in preload as the agent bridge does.

### Renderer
9. `src/resolve/useResolveStatus.ts`: a hook that subscribes to and returns the status.
   `src/resolve/ResolveStatusPill.tsx`: the pill plus a popover:
   - When connected: project › timeline, Resolve edition and version, and a **Disconnect** button.
   - When not connected: the hint, plus **Install plugin** if it isn't installed.
   Show the pill on Home (near the actions) and in the editor header next to the save status. Match the existing
   CSS conventions: look at how the save status and menu buttons are styled, and reuse their classes and tokens.
10. Settings: add a `'resolve'` tab labelled "DaVinci Resolve" with `ResolveSettings`. It shows:
    - the script path
    - installed / not installed / outdated
    - Install / Reinstall / Remove buttons
    - three-step instructions: install, restart Resolve if it was open, then Workspace → Scripts → KathaCut
    - a note that Resolve Free and Studio both work
11. `electron-builder.yml` `extraResources`: add `{ from: resources/resolve, to: resolve, filter: ['**/*',
    '!dev/**'] }`.

## Manual check for the user
1. Run `npm run dev`, then Settings → DaVinci Resolve → Install.
2. Restart Resolve and run Workspace → Scripts → KathaCut. The pill turns *connected* and shows the timeline name.
3. Quit KathaCut. Within about 60 s the Lua script ends: Workspace → Console shows it.
4. Start the script again with KathaCut closed. KathaCut starts. In dev (`npm run dev`), the launched Electron
   has no Vite server, so for dev testing start KathaCut yourself first. Auto-launch is meant for the packaged
   app.
